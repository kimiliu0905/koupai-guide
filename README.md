# PC开播助手·排档经营分析使用教程

这是 PC 开播助手排档、打卡、实时统计与经营诊断的公开使用教程站。

当前阶段目标：搭建教程中心页面框架，确保目录与详情页在手机与电脑上可用。

## 本地预览

可直接双击 `index.html` 打开，也可以在目录下启动任意静态服务。

## Cloudflare Pages 发布建议

1. 新建一个独立 Git 仓库，例如 `koupai-guide`。
2. 将本目录内容提交到仓库。
3. 登录 Cloudflare，进入 Pages，选择 Connect to Git。
4. 选择该仓库。
5. 构建配置保持静态站默认值：
   - Framework preset: None
   - Build command: 留空
   - Build output directory: `/`
6. 发布完成后，Cloudflare 会生成一个 `*.pages.dev` 公网地址。

## Step 1 验收标准

- 电脑浏览器能打开 Cloudflare Pages 生成的公网链接。
- 手机浏览器能打开同一个公网链接。
- 把链接发给他人后，对方无需登录即可阅读。

## Step 2 验收标准

- 电脑端展示为左侧功能目录、右侧教程正文。
- 手机端展示为单栏布局，目录在上、正文在下。
- 点击目录条目后，正文能切换到对应功能。
- 手机端点击目录条目后，页面会自动跳到正文区域。
- 浏览器地址会变成 `/#/模块/功能` 形式，例如 `/#/koupai/start-run`。
- 点击不同目录条目时，正文会切换到对应条目。
- 手机端底部有“目录 / 上一个 / 下一个”快捷操作，方便继续查看其他问题。

## Step 3 验收标准

- 目录已按业务场景分组，而不是简单平铺指令。
- 扣排相关条目覆盖基础运行、麦序规则、排麦调整、任务扣排、置顶禁排、文档报备等模块。
- 打卡模块已单独保留，后续可以继续扩展详细内容。
- 你检查是否有缺少、命名不准确或分类不合理的功能条目。
- 本阶段只校验目录大纲，不校验详细教程正文。

## Step 4 验收标准

- 页面标题改为“PC开播助手·排档经营分析使用教程”。
- 右上角不再展示“手机可读 / 无需登录 / 持续更新”等提示。
- 左侧标题只展示“目录”。
- 高频常见问题前置，面向厅管理读者直接表达问题。
- 功能概览页展示系统亮点、适用对象和数据链路。
- 实时打卡统计目录里包含“看实时私信判断主播状态”的小技巧。
- UI 调整为简约文档风格，以黑白灰为主、少量金色点缀。

## Step 5 验收标准

- 已从飞书文档中筛选并下载有价值的配图。
- 配图只放在匹配的教程条目下，不追求全部搬运。
- 高频问题、打卡设置、主持档、调账、奖励设置、实时私信判断等条目有配图辅助说明。
- 发布时需要一并提交 `images/` 目录。
